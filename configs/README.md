# Configuration

Formal configs are generated by the task binders and written to
`configs/generated/`, which is intentionally ignored by Git because those
files contain machine-local paths and per-run output locations.

Set the paths in `.env` before binding a task. The binder validates that the
qualification decision, metadata, model roots, external source tree, and
Python environment exist before writing a runnable manifest.

Do not reuse a generated manifest on another machine without regenerating it
from the same task metadata and scientific settings.
